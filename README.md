# Proyecto Web (Programación para Internet)

## Descripción:
Este proyecto es una aplicación web desarrollada como parte de la formación académica en la Universidad de Guadalajara (UDG). 
El sistema permite la gestión e interacción con datos dinámicos mediante una interfaz web respaldada por una base de datos MySQL en un entorno local servido con XAMPP.
---
## Tecnologías Utilizadas:
**Frontend:** HTML5, CSS3, JavaScript
**Backend:** PHP
**Servidor Local y Base de Datos:** XAMPP (Apache & MySQL)
